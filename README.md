# 🌾 Agri Assistant – AI Smart Farming Platform for Pakistan

> **Final Project Submission**  
> **Repository:** Public Repository

## Problem Statement
Farmers in Pakistan face severe challenges due to lack of timely expert advice, unpredictable weather, and market price exploitation.

## Solution
Agri Assistant is an AI-powered platform tailored for Pakistani farmers, offering personalized crop recommendations, disease diagnosis, weather alerts, and live market prices.

## Key Features
- **AI Crop Advisor:** Generates crop and fertilizer recommendations based on soil, season, and district.
- **Plant Disease Diagnosis:** Image uploading interface for pest and fungal detection.
- **Live Mandi Prices:** Updated rates across key markets in Punjab and KPK.

## Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** FastAPI (Python), REST API
- **AI Integration:** Google Gemini API
